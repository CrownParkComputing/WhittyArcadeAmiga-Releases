ROM Policy — read first

These bundles contain no arcade ROMs and no ROM-derived data. You must own each game's arcade ROMs and supply them yourself, legally obtained.

Copy the required files from the game's merged MAME ROM set, flattened into the bundle's roms/<set>/ folder (exact filenames and SHA-256 checksums are listed in each bundle's docs/ROM_FILES.txt). The loader verifies them at startup and reports any mismatch on screen.

Games

Shinobi

Sega, 1987 — System 16B
AGA build RTG / P96 build ROM set: shinobi6

Joe Musashi's one-man war on the Zeed syndicate, ported straight from the arcade board. The System 16B program runs natively on your Amiga's CPU with the board's tile, sprite and priority model reproduced, and the full Z80 + YM2151 + uPD7759 soundtrack synthesized from your ROMs and played through Paula.

In the bundle

  • Shinobi — AGA executable (native screens: real A1200/A4000, Amiberry AGA configs)
  • ShinobiRTG — RTG/Picasso96 executable (Pimiga and other RTG-first setups)
  • BuildPack — one-time tool that renders the soundtrack from your ROMs
  • docs/ROM_FILES.txt — exact ROM filenames with SHA-256 checksums
  • Empty roms/shinobi6/ folder — you fill this

System requirements

  • A1200-class AGA Amiga (A1200/A4000)
  • 68040-level CPU recommended — PiStorm and accelerated machines qualify; a stock A1200 does not
  • 64 MB fast RAM, Kickstart 3.0+
  • Amiberry and Pimiga supported (use the RTG build on Pimiga)
  • Best at 60 Hz (NTSC-capable display or emulator)

How it works

  1. Unpack the bundle onto any Amiga drive, or mount the folder as a directory in your emulator.
  2. Add your ROMs. Copy the files listed in docs/ROM_FILES.txt from your legally obtained merged MAME ROM set into roms/<set>/ — flattened, by filename, regardless of the zip's internal subfolders.
  3. Run BuildPack once. It renders the entire soundtrack from your ROMs — the same Z80 + FM + ADPCM sound board the arcade ran — and writes the sound pack next to the game. Takes a few minutes; never needs to run again.
  4. Play. Run the AGA executable on native-screen machines, or the RTG executable on Picasso96 environments such as Pimiga. Joystick or CD32 pad in port 2; full controls in each bundle's README.

Releases and checksums live in the WhittyArcadeAmiga-Releases repository on GitHub.
